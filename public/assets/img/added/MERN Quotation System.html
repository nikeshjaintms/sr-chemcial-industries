Project Name

MERN Quotation Management System with RBAC

Main Flow

1. Login with RBAC

Same user can have multiple roles.

Example:

JavaScript
User: Nehal
Roles: Admin, Sales Executive

Login flow:

  1. User enters email and password.

  2. Backend checks user credentials.

  3. If user has multiple roles, frontend shows role dropdown.

  4. User selects role.

  5. Backend verifies that selected role belongs to that user.

  6. JWT token will contain:

  userId,
  activeRole,
  permissions
}

  1. Dashboard/menu will show based on selected role permissions.

Important: Do not trust only frontend selected role. Backend must verify selected role.

Best Logic for Quotation Price

When user selects product:

Product selected → Fetch current price from Price Master → Auto fill price → User can edit price only if permission allowed

For old quotation:

Old quotation should keep old price.
Do not update old quotation automatically when product price changes.

Final Project Description

You can write your project requirement like this:

This project is a MERN Stack based Quotation Management System with Role Based Access Control. The system allows users to login with multiple roles, select an active role, and access modules based on permissions. It includes master entries like Client Master, Product Category Master, Product Master, and Price Master. Product prices are maintained in the Price Master and can be modified when required. Based on client, product, quantity, and current price, users can create quotations. The system calculates totals and generates quotation PDFs. Old quotations will store price snapshots so price changes do not affect previous quotations.
